# テキストエディタとしてあると便利な機能の調査(2026-08-29)

mymemo の現状(`src/*.js`, `src-tauri/src/*.rs`, README)を読み、「まだ無くて、あると便利な機能」を
実装コスト・依存の有無つきで洗い出したメモ。着手時の優先順位づけに使う。

## 現状のおさらい

| 分類 | 実装済み |
| --- | --- |
| ファイル | タブ、開く/保存/別名保存(文字コード・改行コード選択)、Finder / D&D から開く、UTF-8 / CP932 / EUC-JP / UTF-16 |
| 編集 | undo/redo(タブごと)、矩形選択、複数カーソル(`allowMultipleSelections`)、括弧の対応表示、`indentOnInput`、Tab でタブ文字入力 |
| 検索 | 検索・置換パネル(正規表現・大小区別)、フォルダ grep(ripgrep ライブラリ、5,000 件上限) |
| 表示 | シンタックスハイライト(拡張子・shebang 判定)、4 テーマ、空白・改行コードの可視化、Cmd+ホイールでフォントサイズ |
| 状態 | ステータスバー(行・列 / 文字コード / 改行コード)、テーマと空白表示は `localStorage` に永続化 |

## 調査中に見つかった既存の問題・未記載事項

1. **README に載っていない既定キーバインド**: `defaultKeymap` / `searchKeymap` を丸ごと入れているため、
   以下が既に使える(README のキーバインド表には無い)。
   - `Option+↑/↓` 行を上下へ移動、`Shift+Option+↑/↓` 行を複製
   - `Cmd+Option+↑/↓` 上下にカーソルを追加、`Cmd+D` 次の同じ語を選択に追加、`Cmd+Shift+L` 同じ語をすべて選択
   - `Cmd+Shift+K` 行削除、`Ctrl+L` 行選択、`Cmd+Enter` 下に空行、`Cmd+[` / `Cmd+]` インデント
   - `Cmd+/` コメント切替(言語が判定できたファイルのみ)、`Cmd+Shift+\` 対応する括弧へ
   - `Cmd+Option+G` 行へ移動(パネルの文言は `japanesePhrases` で翻訳済み)、`Cmd+G` / `Cmd+Shift+G` 次・前の一致
   - `Cmd+クリック` カーソル追加
2. **Tab キーの不整合**: 選択なしの Tab は `\t` を入力するが、選択ありの Tab / Shift+Tab は `indentUnit`(4 スペース)で
   インデントする(`insertTab` → `indentMore` の仕様)。タブ幅・ソフトタブ設定を入れるときに合わせて解消したい。
3. **フォントサイズが永続化されない**: `main.js` の `fontSize = 13` は起動のたびにリセット。メニュー項目(Cmd+= / Cmd+- / Cmd+0)も無い。
4. **巨大ファイルのガードが無い**: grep は 20MB 超をスキップするが `read_file` には上限が無く、数百 MB を開くと固まる。
5. **検索パネルに一致件数が出ない**: 「3 / 12」のような表示が無いので置換前に規模が分からない。
6. **ディスク上の変更を検知しない**: 他アプリで書き換えたファイルを保存すると黙って上書きする。

## 候補一覧

### A. 小さくて効く(新規依存なし・1 コミット規模)

| 機能 | なぜ便利か | 実装の当たり |
| --- | --- | --- |
| 行の折り返し切替(表示メニュー) | メモ・日本語の長文で横スクロールが不要になる。エディタの基本機能 | `EditorView.lineWrapping` を Compartment で切替。`whitespace.js` と同じパターン(メニューのチェック同期 + `localStorage`) |
| フォントサイズの永続化 + 拡大/縮小/リセットのメニュー | 毎回 Cmd+ホイールで調整している状態をなくす | `theme.js` と同じく `localStorage`。メニューに `Cmd+=` / `Cmd+-` / `Cmd+0` |
| 「行へ移動」をメニューに追加(`Cmd+L`) | 既存の `gotoLine` を発見できる場所に出す | `search` メニューに項目追加 → `gotoLine(view)` |
| 文字数・選択文字数の表示 | メモ用途では行・列より文字数の方が見たい(字数制限のある文章など) | ステータスバーに `doc.length` と選択範囲の長さ。改行や全角の数え方だけ決める |
| 最近使ったファイル | Finder を経由せず開き直せる | `localStorage` に最大 10 件。ネイティブメニューは Rust 側で `MenuItem` を差し替え(`ThemeMenuItems` と同じ State 管理) |
| セッション復元(開いていたタブ・カーソル位置) | 起動するたびに開き直す手間をなくす。「メモ」なら未保存の無題タブも残したい | 終了時に `{path, cursor, 無題の本文}` を保存し起動時に復元。無題の本文は `localStorage` か `app_data_dir` に |
| ディスク上の変更検知 + 「保存済みの状態に戻す」 | 他ツールで編集したファイルを上書きしてしまう事故を防ぐ | `read_file` の戻りに mtime を含め、ウィンドウの focus 時と保存前に Rust で mtime を比較。差があれば「再読み込み / このまま」を確認 |
| タブ操作の拡充 | タブが増えたときの移動コスト | `Cmd+1〜9` で切替、ドラッグで並べ替え、`Cmd+Shift+T` で閉じたタブを復元、中クリックで閉じる、右クリック「他を閉じる」 |
| Finder で表示 / パスをコピー | 開いているファイルの場所へすぐ行ける | Rust 側で `open -R <path>`(`std::process::Command`、プラグイン不要)。クリップボードは `navigator.clipboard` |
| grep フォルダの既定をアクティブファイルの場所に | 毎回フォルダを選ぶ手間をなくす | `grep.js` の `searchDir` 初期値をアクティブタブの `dirname` に。ルート選択は残す |
| 巨大ファイルの警告 | 固まる前に止める | `read_file` でサイズを見て、閾値(例 50MB)超は確認 → 開く場合はハイライト・空白表示を無効化 |
| README の既定キーバインド追記 | 上の「未記載事項 1」 | ドキュメントのみ |

### B. 中規模(新規依存なし・設計を少し要する)

| 機能 | なぜ便利か | 実装の当たり |
| --- | --- | --- |
| タブ幅・ソフトタブ設定 | 「未記載事項 2」の不整合解消。言語ごとの好み(Python は 4 スペース、Go はタブ)に合わせられる | `EditorState.tabSize` と `indentUnit` を Compartment 化。ファイル先頭の字下げから自動判定するとさらに良い |
| テキスト変換メニュー | CotEditor 等にある定番。メモ・データ整形で頻用 | 大文字/小文字、全角⇄半角、ひらがな⇄カタカナ、行のソート・重複削除・逆順、末尾空白の削除、空行の削除。すべて `view.dispatch` 1 回で undo 可能 |
| 検索パネルの一致件数・「選択範囲内を置換」 | 置換の規模が見える。部分置換ができる | `SearchQuery.getCursor()` で件数を数える(大きなファイルは上限つき)。範囲内置換は選択範囲を保持して自前でループ |
| grep のファイル絞り込みと置換 | `*.md` だけ、`node_modules` 除外など。複数ファイル置換は大きめの機能 | Rust 側の `ignore::WalkBuilder` に `overrides` を追加。置換は結果から対象を選んで `write_file` |
| コード折りたたみ | 長い JSON / Markdown の見出し単位で畳める | `foldGutter()` + `foldKeymap`(`@codemirror/language` 同梱)。表示メニューで ON/OFF |
| 括弧・引用符の自動補完(任意 ON) | コード編集時は楽だが、散文では邪魔になるので設定制 | `closeBrackets()`(`@codemirror/autocomplete` 同梱)を Compartment で |
| 単語補完(任意 ON) | 同じ文書内の語を補完 | `autocompletion({ override: [completeAnyWord] })` |
| Markdown 入力支援 | リスト・引用の継続、`- [ ]` など。メモの主用途 | `markdownKeymap`(`@codemirror/lang-markdown` 同梱)を Markdown 判定時だけ言語 Compartment に同梱 |
| 文字コードを保存せずに変更 | 「別名保存」を経ずに CP932 → UTF-8 にしたい | ステータスバーの文字コード・改行コードをクリックでポップアップ。改行コードは `convert_eol:` の流用 |
| カーソル位置の復元(ファイルごと) | 長いファイルを開き直したとき前回の場所に戻る | セッション復元に含める。`localStorage` に `{path: {line}}` |

### C. 大きい・依存追加が要る(着手前に要相談)

| 機能 | 備考 |
| --- | --- |
| ウィンドウの位置・サイズの復元 | `tauri-plugin-window-state` を追加すれば数行。自前なら `onResized`/`onMoved` を `localStorage` に |
| Markdown プレビュー | レンダラ(`marked` / `markdown-it`)の追加が要る。CSP が `null` なので XSS 対策も併せて検討 |
| 分割表示(2 ペイン) | `EditorView` を 2 つ持ち、同じ `EditorState` の共有か別タブか設計が要る。`tabs.js` が単一 view 前提 |
| 複数ウィンドウ | `tabs.js` の状態がモジュール変数なので大きめの改修 |
| フォルダを開く(ファイルツリー) | サイドバー UI と Rust 側のディレクトリ走査。grep と組み合わせると「プロジェクト」化する |
| URL / パスをクリックで開く | `tauri-plugin-opener` の追加 |
| 自動保存 | 「メモ」としてはあり。既存ファイルの自動上書きは事故要因なので、無題タブの下書き保存(セッション復元)から始めるのが安全 |
| 印刷 | `window.print()` は WKWebView で動くが、書式調整が必要 |

## おすすめの着手順

1. **README に既定キーバインドを追記**(発見性の改善だけで機能が増える)
2. **行の折り返し切替**、**フォントサイズ永続化 + メニュー**(どちらも `whitespace.js` / `theme.js` の写しで済む)
3. **文字数表示**、**行へ移動のメニュー化**(ステータスバー・メニューの小改修)
4. **セッション復元(無題タブの下書き含む)** + **最近使ったファイル**(「メモ」としての使い勝手に直結)
5. **ディスク上の変更検知**(データ消失の防止。Rust 側の mtime 比較だけで済む)
6. その後 B のうち「タブ幅設定」→「テキスト変換」→「検索の件数・範囲内置換」

いずれも「1 コミット 1 目的」で、`whitespace.js`(Compartment + メニュー同期 + 永続化)のパターンに乗せると
`editor.js` / `lib.rs` の触る場所が揃う。
