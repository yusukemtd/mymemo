# mymemo

Mac 向けの軽量テキストエディタ(Tauri 2 + CodeMirror 6)。

## 機能

- **タブ**: 複数ファイルをタブで切り替え(未保存は ● 表示)
- **Finder から開く**: 右クリック「このアプリケーションで開く」、ダブルクリック(既定アプリに設定した場合)、Dock アイコンやウインドウへのドラッグ&ドロップでファイルを開ける
  - テキスト系の拡張子(txt / md / log / csv / json / yaml / toml / xml / html / css / js / ts / py / rs / sh など)と、macOS がテキスト(`public.text`)と判定するファイルを対象として宣言している。それ以外のファイルは「その他…」から選ぶ
  - 「このアプリケーションで開く」の候補には出るが、既定アプリを自動で奪わない設定(`LSHandlerRank = Alternate`)。既定にしたい場合は Finder の「情報を見る > このアプリケーションで開く > すべてを変更」で設定する
- **矩形選択**: `Option + ドラッグ` で矩形選択 → `Cmd+C` / `Cmd+X` で列単位のコピー・切り取り
- **検索・置換**: `Cmd+F` で検索パネル(パネル内の「正規表現」「大文字小文字を区別」トグル)。置換もパネル内で可能
  - 一致件数を表示(選択中の一致があれば「3 / 12 件」。10,000 件で打ち切り「10,000+ 件」)
  - 「選択範囲内を置換」で選択範囲(複数選択・矩形選択も可)の中の一致だけをすべて置換する。置換文字列は「すべて置換」と同じく `\n` `\t` と、正規表現なら `$1` `$&` が使える
- **grep**: `Cmd+Shift+F` でフォルダ横断検索。結果クリックで該当行へジャンプ
  - 「ファイル名」欄で `*.md` `src/**/*.js` `!node_modules` のように対象を絞り込める(gitignore と同じ書き方。空白または `,` 区切りで複数)
  - 「置換文字列」+「すべて置換」で、一致をすべて置換してファイルへ書き戻す(先に検索してファイル数・行数を確認する。**元に戻せない**)。正規表現なら `$1` `${name}` を展開。開いているタブには自動で反映される(未保存の編集があるタブは確認)
- **改行コードの行ごとの保持**: LF / CR / CRLF が混在するファイルもそのまま開き、そのまま保存する。ステータスバーには `LF` のように表示し、混在時は `混在 (CRLF 12, LF 3)` と内訳を出す
  - Enter で入れた改行はその行(最終行なら直前の行)と同じ改行コードになる
  - 複数行にまたがる置換では、消えた改行の改行コードを挿入される改行が順に引き継ぐ。undo で消した改行を戻すときも元の改行コードに戻る
  - 「名前を付けて保存」の改行コードは既定で「そのまま」(行ごとに保持)。LF / CRLF / CR を選ぶと全行をそれに統一して保存する
  - 「編集 > 改行コードを変換 > LF / CRLF / CR」で保存せずに全行を統一できる(未保存扱いになり、`Cmd+Z` で戻せる)
  - 制約: 検索・置換は改行コードの種別を区別しない(本文上の改行は 1 種類なので、正規表現の `\n` は全種別にマッチし、`\r` は何にもマッチしない)。行単位で改行コードを検索・変換することはできない
  - 制約: CR 改行の直後にある空行を LF 改行にした場合、バイト列は `\r\n` になり CRLF 1 つと区別できないため、開き直すと 1 行に見える(ファイル形式上の曖昧さで、他のエディタでも同じ)
- **空白文字・改行の可視化**: 「表示 > 空白文字・改行を表示」で切替(既定は表示、設定は保存される)
  - 半角スペース `·` / NBSP `·` に警告色の枠 / 全角スペース `□`(枠) / タブ `→`
  - 各行末にその行の改行コードを示す記号: LF `↓` / CR `←` / CRLF `↵`(最終行の後ろに改行がなければ付かない)
- **文字コードの変更(読み直さない)**: 「編集 > 文字コードを変換」またはステータスバーの文字コードをクリックで、保存時の文字コードだけを変える(本文はそのまま。未保存扱いになる)。ファイルを別の文字コードとして読み直すのは「ファイル > 文字コードを指定して開く」。ステータスバーの改行コードをクリックすると「改行コードを変換」と同じメニューが出る
- **Markdown の書式ショートカット**: 「編集 > Markdown」の太字 `Cmd+B` / 斜体 `Cmd+I` / 取り消し線 `Cmd+Shift+X` / インラインコード `Cmd+E` / リンク `Cmd+K`。選択範囲を `**` などで囲み、既に囲まれていれば外す(太字と斜体の重ね `***` も区別)。選択が無ければ対を挿入してその間にカーソルを置く。リンクは URL を選んでいれば `[](url)`、テキストなら `[text](|)`。どのファイルでも使える
- **Markdown 入力支援**: `.md` では Enter でリスト(`-` `*` `1.`)・引用(`>`)・チェックボックス(`- [ ]`)を次の行に継続し、空の項目で Enter すると項目を終える(2 つ目の項目では先に空行が入り、もう一度 Enter で終える)。行頭のマークアップは Backspace でまとめて消せる
- **インデント設定(タブ幅・ソフトタブ)**: 「編集 > インデント」でタブ幅(2 / 4 / 8)と「スペースでインデント(ソフトタブ)」をタブごとに切替。ステータスバーに `タブ幅 4` / `スペース 2` と表示
  - ファイルを開いたときは字下げから自動判定する(タブ始まりの行が多ければタブ、そうでなければ字下げ幅から 2 / 4 / 8 を推定)。字下げが無いファイルと無題タブはメニューで最後に選んだ設定になる(保存される)
  - Tab キーはソフトタブなら次のタブ位置までスペースを入れ、選択範囲のインデントと自動インデントもスペースになる
- **括弧・引用符の自動補完(任意 ON)**: 「編集 > 括弧・引用符を自動で閉じる」を ON にすると `(` `[` `{` `'` `"` の入力で閉じ記号を補い、閉じ記号の入力や Backspace は対で扱う。散文では邪魔になるので既定は OFF(設定は保存される)
- **単語補完(任意 ON)**: 「編集 > 単語を補完する」を ON にすると、同じ文書内の単語を入力に合わせて候補表示する(`Ctrl+Space` で手動表示、`↑` / `↓` で選択、Enter で確定、Esc で閉じる)。既定は OFF(設定は保存される)
- **テキスト変換**: 「編集 > テキスト変換」で行を昇順 / 降順にソート(コードポイント順)、重複する行を削除(最初の 1 つを残す)、空行(空白だけの行も)を削除。選択範囲があればその範囲にかかる行だけ、無ければ全行が対象。`Cmd+Z` で 1 回で戻る
  - 制約: 改行コードが混在するファイルでは、並べ替えた行の改行コードは元の位置のものが使われる(行に付いて移動しない)
- **ディスク上の変更検知**: ウィンドウが前面に戻ったとき、開いているファイルが他のアプリで変更されていれば読み直す(未保存の編集があるタブは確認してから。断ると以後そのタブは保存時にだけ確認する)。上書き保存のときもディスク上で変更されていれば上書きするか尋ねる。「ファイル > 保存済みの状態に戻す」で編集を捨てて読み直せる
  - 読み直したタブの undo 履歴は残らない。カーソル位置は保つ
- **最近使ったファイル**: 「ファイル > 最近使ったファイルを開く」に、開いた・保存したファイルを新しい順に 10 件表示。「履歴を消去」で消せる。開けなくなったファイルは選んだときに履歴から外れる
- **セッション復元**: 終了時に開いていたタブ(パス・文字コード・カーソル位置)と無題タブの本文を保存し、次回起動時に復元する
  - 無題タブは保存していなくても内容が残るので、終了時の未保存確認の対象にならない(`Cmd+W` で閉じたときは確認する)
  - ファイルを開いたタブの未保存の編集は保存しない(終了時に破棄の確認をする)。復元時に無くなっていたファイルは飛ばす
  - 保存先は localStorage。下書きの合計が数 MB を超えると保存できず、その場合は終了時の確認対象になる
- **コード折りたたみ**: 言語が判定できたファイルでブロック・関数・Markdown の見出しなどを折りたためる。ガターの `▸` / `▾` をクリックするか「表示 > 折りたたみ」(`Cmd+Option+[` / `]` で折りたたむ / 展開、`Ctrl+Option+[` / `]` ですべて)。「折りたたみガターを表示」で `▸` の表示を切替(既定は表示、設定は保存される)。プレーンテキストでは折りたためない
- **行の折り返し**: 「表示 > 行を折り返す」で切替(既定は折り返さない、設定は保存される)
- **文字数**: ステータスバーに全文の文字数(改行を除く。絵文字などサロゲートペアは 1 文字)を表示。選択中は「選択 12 / 1,234 文字」のように選択範囲の文字数も出る
- **フォントサイズ**: 「表示 > 拡大 / 縮小 / 標準サイズ」(`Cmd+=` / `Cmd+-` / `Cmd+0`)または `Cmd+スクロール`。8〜48px、設定は保存される

## 開発

```sh
npm install
npm run tauri dev     # 開発起動
npm run tauri build   # .app 生成 → src-tauri/target/release/bundle/macos/mymemo.app
```

生成した `.app` は `/Applications` にコピーして使う。Finder の「このアプリケーションで開く」に出てこない場合は、LaunchServices に手動で登録し直す:

```sh
/System/Library/Frameworks/CoreServices.framework/Frameworks/LaunchServices.framework/Support/lsregister -f /Applications/mymemo.app
```

`src-tauri/target/` 内のビルド成果物も LaunchServices に登録されると候補に mymemo が 2 つ並ぶので、その場合は `lsregister -u <target 内の mymemo.app>` で登録を外す。

## テスト

```sh
npm test                        # フロントエンド (vitest): 言語検出・タブ管理
cd src-tauri && cargo test      # Rust: エンコーディング判定・読み書き・grep・Finder から渡されたファイルの受け渡し
```

## grep の仕様・制約

grep は Rust 側で ripgrep のライブラリ(grep-searcher / ignore)を使用。各ファイルをエディタと同じ自動判定(BOM → UTF-8 → CP932 → EUC-JP)でデコードしてから検索するため、CP932 / EUC-JP / UTF-16(BOM 付き)のファイルにも日本語などマルチバイトのパターンがヒットする。

- **エンコーディング判定はヒューリスティック**: CP932 と EUC-JP の両方として妥当なバイト列(EUC-JP のかな中心のテキストなど)は CP932 と判定されることがある。エディタで開いたときと同じ解釈なので、ヒット行番号は常に「開いた結果」と一致する
- **UTF-16 は BOM 付きのみ対象**: BOM のない UTF-16 はバイナリ(NUL バイト含む)としてスキップ
- **20MB を超えるファイルはスキップ**(エンコーディング判定のため全読みする都合)
- **バイナリ(NUL バイトを含むファイル)はスキップ**
- **.gitignore と隠しファイルを尊重**して走査する
- **結果は 5,000 件で打ち切り**(ステータスに「上限で打ち切り」と表示)
- **置換は文字コード・改行コード・UTF-8 の BOM を保って書き戻す**。正しく読めない(文字化けする)ファイルと、その文字コードで表現できない置換文字列は書き換えない(後者はエラーを表示し、そこで止まる)
